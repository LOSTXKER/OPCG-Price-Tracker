## North-star
MINE = one unified cross-game list per user at a flat URL; game derived per-item from `card.set.game`. Two game controls, never overlapping: **header pill NAVIGATES catalog** (never touches MINE — 1f07ff9 invariant), **in-page segmented chips FILTER the current list** (per-page local session state). Honey = only interactive accent (<5%); per-game tint = thin layer over honey (crest/glow/frame), never repaint, driven by `GameConfig.accentTint`. Green/red = P/L only. One hero number/screen, tabular numerals, ▲/▼ deltas, skeleton not spinner, flat+hairline; single-game user sees zero multi-game chrome.

## Key rules / risks
- `--game-tint` defaults to `var(--primary)` → NEVER put on button/CTA/ring (silently looks right for OPCG, breaks on Pokémon). Per-row tint set inline per element (not shell-level).
- Portfolio breakdown renders ALL-GAMES view only, UNMOUNTS when scoped (one hero rule).
- Watchlist `scopedByGame` = game filter ONLY (not search/set/direction).
- Alert grouping: `AlertRow showGameBadge={false}` under a game group, `true` in flat/scoped.
- Notify API: `apiHandler` + Zod schema + `{ ok: true }`/`{ error }` envelope.
- All new value surfaces respect `hideBalance`. All new motion honors `prefers-reduced-motion`.
- Multi-game visible only via `?demo=multigame` until Phase G backfills real data.
